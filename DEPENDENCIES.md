# Third party dependencies

This project relies on several open-source tools and libraries.

Please refer to their respective repositories or websites for their license information.


| Tool / Library                                                                                             | Note              | Depend                                                  |
| ---------------------------------------------------------------------------------------------------------- | ----------------- | ------------------------------------------------------- |
| [Python](https://github.com/python/cpython) (>= 3.10)                                                      | Base language     | Required                                                |
| [PySide6](https://wiki.qt.io/Qt_for_Python)                                                                | Core              | Required                                                |
| [mutagen](https://github.com/quodlibet/mutagen)                                                            | Metadata parsing  | Required                                                |
| [debus-next](https://pypi.org/project/dbus-next/)                                                          | MPRIS integration | Required                                                |
| [Qt Multimedia FFmpeg](https://doc.qt.io/qt-6/qtmultimedia-attribution-ffmpeg.html)                        | Audio backend     | Required                                                |
| [JetBrainsMono Nerd Font](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/JetBrainsMono) | Icon glyphs       | Somewhat Required (bundled on python and Windows build) |
